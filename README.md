## Descripción

Lights Out es un juego de lógica desarrollado en Python.

El objetivo es apagar todas las luces del tablero. Cuando el jugador selecciona una luz, también cambian las luces que se encuentran arriba, abajo, a la izquierda y a la derecha.

## Funciones principales

- Juego mostrado en la terminal.
- Diferentes colores.
- Tres niveles de dificultad.
- Tableros de 5 × 5, 7 × 7 y 9 × 9.
- Contador de movimientos.
- Modo de ayuda.
- Tableros generados aleatoriamente.
- Pantalla de victoria.

## Requisitos

- Python 3.
- Paquete `keyboard`.
- Una terminal compatible con colores.

## Cómo descargarlo

```bash
git clone https://github.com/Nfren4563/LightsOut.git
cd LightsOut
cd "lightsout - completo"
```

## Instalación

Instala la dependencia necesaria:

```bash
pip install keyboard
```

## Ejecución

```bash
python main.py
```

## Controles

| Tecla | Función |
|---|---|
| Flechas | Moverse por el tablero |
| Enter | Activar una luz |
| T | Activar o desactivar la ayuda |
| Q o Esc | Regresar o salir |

## Dificultades

- Fácil: tablero de 5 × 5.
- Medio: tablero de 7 × 7.
- Difícil: tablero de 9 × 9.
